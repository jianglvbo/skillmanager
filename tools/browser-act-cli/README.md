# browser-act-cli

BrowserAct 浏览器自动化 CLI 工具，专为 AI Agent 设计。

## 安装

```bash
# 需要 uv + Python 3.12+
uv tool install browser-act-cli --python 3.12

# 国内用户可用清华镜像加速
uv tool install browser-act-cli --python 3.12 --index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 验证
browser-act --version
```

## 更新

```bash
uv tool upgrade browser-act-cli
```
