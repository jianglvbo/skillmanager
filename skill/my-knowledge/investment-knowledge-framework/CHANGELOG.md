# Changelog

## 4.1.1 (2026-06-22)

- **Skill 解耦**：移除所有对其他 skill 的显式引用（link-analysis、xq-registry），各 skill 只描述自身领域

## 4.1.0 (2026-06-22)

- **仪表盘上移**：仪表盘从投资分析框架内上移至 vault 根目录 `仪表盘/`
- **目录精简**：投资分析框架只保留 `原始资源仓库/` 和 `维基仓库/`，移除 `首页.md`、`仪表盘/`
- **旧目录数据修复**：`3 原始资源/` 和 `5 问答看板/` 残留数据迁移至正确位置

## 4.0.0 (2026-06-21)

- **架构升级**：从单框架升级为双框架架构（投资分析框架 + 博主分析框架），一个 vault（我的知识库）下两个子框架
- **博主画像摘除**：博主画像相关内容从维基仓库移出，迁移至独立的博主分析框架
- **三维分类**：新增三维正交分类体系（category + content_type + time_sensitivity）
- **类型模块模板**：新增按内容类型区分的模板模块（方法论/案例分析/数据解读/观点评论/市场综述）
- **自动验证机制**：新增 validations frontmatter 数组，方向性判断自动标记
- **处理指令传播**：新增 _route/_profile/_alias/_xueqiu 等临时字段，通过 frontmatter 在流水线中传递
- **路径更新**：所有 Dataview 查询、wikilink 路径同步更新为 `投资分析框架/` 前缀
- **设计原则明确**：skill 只定义流程步骤和输入输出，不包含定时任务或调度策略
