# 常用提问模板

> 问答维基仓库时的常用提问模板。

## 板块分析

```
请基于维基仓库，分析【XX板块】的投资逻辑：
1. 板块整体情况和核心驱动力
2. 重点标的及各自优势
3. 当前估值水平和风险点
4. 相关博主的主要观点
```

## 个股分析

```
请基于维基仓库，分析【XX公司】：
1. 公司核心竞争力
2. 所属板块的情况
3. 关键财务数据和估值
4. 相关博主的主要观点
5. 主要风险点
```

## 博主观点汇总

```
请基于维基仓库，汇总关于【XX博主】的信息：
1. 投资风格和能力圈
2. 近期关注的板块和个股
3. 历史判断的准确率
4. 值得跟踪的观点
```

## 宏观环境分析

```
请基于维基仓库，分析当前宏观环境：
1. 主要宏观变量
2. 对各板块的影响
3. 需要关注的风险
```
