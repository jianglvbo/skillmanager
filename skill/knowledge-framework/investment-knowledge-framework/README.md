# investment-knowledge-framework

投资分析知识管理框架的完整操作手册。基于 Obsidian vault 的五层循环流水线：粗制品 → 原始资源 → 维基仓库 → 问答看板 → 回流。

覆盖粗加工、提炼（多维度）、问答、迭代四个核心流程，包含 frontmatter 模板、标签体系、审查规则和交叉链接原则。

## 适用场景

- 用户提供投资文章链接要求处理
- 用户说"提炼"要求创建维基条目
- 用户说"根据框架"要求问答分析
- 用户提到"投资分析框架"/"知识库"相关的任何操作

## 安装

无需额外依赖。直接使用 Obsidian MCP 工具操作 vault 文件。
