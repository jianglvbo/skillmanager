# 帖子质量评分

> 本文档是 `blogger-refine` 的按需引用。在提炼每篇文章时，按本规则计算该文章的 post_score 增量。
> post_score 可升可降——高质量帖加分，低质量帖倒扣。

---

## 公式

```
本轮增量 = 内容类型基础分 × 来源权重 × 质量系数
post_score = 已有 post_score + 本轮增量（四舍五入取整）
```

---

## 一、内容类型基础分

按文章的核心内容定档，只看这篇讲了什么。

| 类型 | 基础分 | 典型特征 | 适用平台 |
|:---|:---:|:---|:---|
| 方法论 / 投资体系 | 10 | 系统性框架输出（仓位规则、选股标准、风控体系） | 长文、帖子 |
| 案例分析 / 个股深度 | 8 | 单一标的深度拆解，含估值/逻辑/风险 | 帖子、长文、视频 |
| 观点评论 | 6 | 对市场/板块/概念/事件的独立判断 | 全平台 |
| 数据解读 | 5 | 以数据表格/图表为核心的分析 | 帖子、长文 |
| 市场综述 / 行情复盘 | 3 | 当日/当周行情描述，事件速评 | 帖子、视频、公众号 |
| 生活随笔 / 情绪宣泄 | 1 | 纯个人日常、投资心理吐槽、无实质判断 | 全平台 |

### 档位判断优先级

1. 先看有没有完整的逻辑框架 → 方法论（10）
2. 再看是不是围绕单一标的深度展开 → 案例分析（8）
3. 有没有对某个话题的独立判断 → 观点评论（6）
4. 主体是数据罗列还是观点输出 → 数据解读（5）
5. 只是描述"今天涨了跌了" → 市场综述（3）
6. 以上都不沾 → 生活随笔（1）

## 二、来源权重

| 来源 | 权重 | 判断依据 |
|:---|:---:|:---|
| 原创 | ×1.0 | 博主本人撰写/口述，有独立观点 |
| 深度转述 | ×0.7 | 转述他人观点但有自己补充分析 |
| 转载 / 简单转述 | ×0.5 | 二次传播，无实质原创内容 |
| 纯引用 | ×0.3 | 仅贴链接/截图/原文，无任何点评 |

### 跨平台判定

| 平台 | 来源判定 |
|:---|:---|
| 雪球帖子 | 非转发=原创，转发=深度转述或转载 |
| 抖音/视频转录 | 博主口述=原创，读稿/引述他人=深度转述 |
| 公众号长文 | 署名作者名=原创，转载声明=转载 |
| 访谈/对话 | 受访者为博主本人=原创，受访者为他人=转载 |

## 三、质量系数（可负数）

质量系数决定本轮增量是加还是扣。默认 ×1.0（不加不扣），命中以下条件时取**最严系数**（最小值）。

### 加分条件

| 条件 | 系数 | 标准 |
|:---|:---:|:---|
| （无触发） | ×1.0 | 默认 |

### 扣分条件（从轻到重）

| 条件 | 系数 | 标准 |
|:---|:---:|:---|
| 偏水 | ×0.5 | >50% 篇幅讲个人日常/情绪/重复观点，可提炼信息 ≤2 条 |
| 篇幅短且无观点 | ×-0.5 | 不到 200 字，无明确判断，仅情绪表达 |
| 标题党 | ×-0.8 | 标题夸张煽动但正文无实质内容支撑 |
| 风格漂移 | ×-0.8 | 与博主一贯风格/能力圈明显背离，疑似跟风或代笔 |
| 注水严重 | ×-1.0 | 通篇无独立判断，纯行情数字罗列或情绪宣泄 |

### 扣分条件详解

**偏水**（×0.5）：
- 文章中大量篇幅在回忆往事、描述日常生活、抒发个人情感
- 投资相关部分只有一两句笼统表态（"长期看好""相信价值"类）
- 不扣成负数，只是加分减半

**篇幅短且无观点**（×-0.5）：
- 字数 < 200 字（约一条微博的长度）
- 内容只有「看好」「不看好」「牛逼」等无理由表态
- 或纯转发无评论、纯晒持仓截图无分析
- 注意：精炼的短观点（如段永平一句"不看好"加三个理由）不算此列

**标题党**（×-0.8）：
- 标题使用「暴涨」「暴跌」「99% 的人不知道」等夸张词
- 正文与标题情绪不符，或完全没有逻辑论证
- 常见于公众号流量文

**风格漂移**（×-0.8）：
- 博主长期做价值/逆向/消费，突然推短线题材/技术分析/完全不碰的赛道
- 除非博主明确声明在研究新领域（此时降一级到偏水 ×0.5）
- 判断依据：对比画像中 `style_keywords` 和 `markets` 字段

**注水严重**（×-1.0）：
- 整篇文章无任何独立判断，全是「沪指涨了 X%」「茅台跌了 Y 元」
- 或从头到尾情绪宣泄无任何逻辑
- 扣完基础分相当于本篇文章对博主画像零贡献

## 四、平台特殊规则

### 雪球帖子

| 特征 | 处理 |
|:---|:---|
| 转发 + 一句话点评 | 观点评论（6）× 深度转述（0.7） |
| 转发无点评 | 纯引用（0.3）× 基础分 1 = 最多 +0.3，可忽略 |
| 纯晒持仓图无分析 | 篇幅短无观点（-0.5） |
| 评论区互动被提炼 | 按观点评论（6）计算 |

### 抖音 / 视频转录

| 特征 | 处理 |
|:---|:---|
| 逐字稿转录 | 来源 = 原创（博主口述） |
| 转录中有大量口语填充词 | 不扣分（转录特征，非内容问题） |
| 视频 < 60 秒 | 篇幅短且无观点检查更严格 |
| 读稿/背稿式 | 来源降为深度转述（0.7） |

### 公众号长文

| 特征 | 处理 |
|:---|:---|
| 署名作者 = 博主本人 | 原创（×1.0） |
| 文末有「本文转载自」声明 | 转载（×0.5） |
| 广告/软文占比 > 30% | 偏水（×0.5） |
| 头部广告 + 尾部广告但正文正常 | 不扣分 |

### 访谈 / 对话

| 特征 | 处理 |
|:---|:---|
| 博主是受访者 | 原创（×1.0），按对话中输出的观点定基础分 |
| 博主是采访者 | 深度转述（×0.7），基础分看被采访者输出的内容 |
| 仅转发访谈链接无点评 | 纯引用（×0.3） |

## 五、批量提炼时的滚动规则

1. 同一博主当日多篇文章 → 逐篇独立计算，累加
2. 同一篇文章被提炼为多个维基条目 → 只算一次分
3. 画像更新（非首次提炼）时 → 只计算本篇文章的增量
4. post_score 可为负数 → 表示该博主近期内容质量下降
5. 负分博主需在审查报告中标注提醒

---

## 六、打分自检

每篇文章提炼完毕时检查：

- [ ] 内容类型定档是否合理？有没有更高优先级的档？
- [ ] 来源权重：是否确认为原创？有没有被转载声明漏掉？
- [ ] 质量系数：逐条扫描扣分条件，取最严的那条
- [ ] 计算结果：本轮增量 ≈ 体感质量吗？偏差大就回头复查
- [ ] 负分文章：确认扣除理由充分，在画像更新中标注原因
