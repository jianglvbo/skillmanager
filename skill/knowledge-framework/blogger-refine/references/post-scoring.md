# post_score 评分规则

> `blogger-refine` 第六步加载。提炼每篇文章时计算 post_score 增量。

---

# Default stance

## 核心原则
- 三因子评分：类型 × 来源 × 质量，不可跳过任何因子
- 扫描顺序优先：质量系数从重到轻扫描，命中即停
- 幂等性：同一文章只计分一次（检查 sources 去重）

## 禁止行为
- 绝不凭感觉打分
- 绝不因喜好调分
- 绝不叠加扣分系数
- 绝不将偏水判为负数

---

# Workflow

1. 第一步：定档内容类型 → 按优先级扫描获取基础分
2. 第二步：判定来源权重 → 对照平台规则
3. 第三步：扫描质量系数 → 从重到轻，命中即停
4. 第四步：套公式 → `本轮 = 基础分 × 权重 × 系数（取整）`
5. 第五步：累加 → `post_score（新）= post_score（旧）+ 本轮`

---

# 一、内容类型基础分

按优先级扫描，命中即停：

```
方法论（10）→ 案例分析（8）→ 观点评论（6）→ 数据解读（5）→ 市场综述（3）→ 生活随笔（1）
```

| 类型 | 分 | 典型特征 |
|:---|:---:|:---|
| 方法论 / 投资体系 | 10 | 系统性框架（仓位规则、选股标准、风控体系） |
| 案例分析 / 个股深度 | 8 | 单一标的估值+逻辑+风险深度拆解 |
| 观点评论 | 6 | 对市场/板块/事件有独立判断 |
| 数据解读 | 5 | 以数据表格/图表为核心 |
| 市场综述 / 行情复盘 | 3 | 当日行情描述、事件速评 |
| 生活随笔 / 情绪宣泄 | 1 | 个人日常、心理吐槽 |

---

# 二、来源权重

| 来源 | 权重 |
|:---|:---:|
| 原创（本人撰写/口述） | ×1.0 |
| 深度转述（转述+补充分析） | ×0.7 |
| 转载（二次传播无原创） | ×0.5 |
| 纯引用（仅链接/截图无点评） | ×0.3 |

### 平台判定

| 平台 | 原创 | 其他 |
|:---|:---|:---|
| 雪球 | 非转发 | 转发+点评=深度转述，转发无点评=纯引用 |
| 抖音/视频 | 博主口述 | 读稿=深度转述 |
| 公众号 | 署名作者 | 「转载自」=转载 |
| 访谈 | 博主受访 | 博主采访=深度转述 |

---

# 三、质量系数

按扫描顺序，命中即停。系数可负数（倒扣）。

| 扫描顺序 | 条件 | 系数 | 标准 |
|:---|:---|:---:|:---|
| 1 | 注水严重 | ×-1.0 | 通篇无独立判断，纯行情罗列/情绪宣泄 |
| 2 | 风格漂移 | ×-0.8 | 与 `style_keywords`/`markets` 明显背离 |
| 3 | 标题党 | ×-0.8 | 标题夸张煽动，正文无论证 |
| 4 | 短篇无观点 | ×-0.5 | <200 字，纯「看好」「牛逼」无理由 |
| 5 | 偏水 | ×0.5 | >50% 篇幅日常/情绪，可提炼信息 ≤2 条 |
| — | 正常 | ×1.0 | 以上均不命中 |
