# 帖子质量评分

> `blogger-refine` 按需引用。提炼每篇文章时用本规则计算 post_score 增量。

---

## 核心公式

```
本轮增量 = 内容类型基础分 × 来源权重 × 质量系数（四舍五入取整）
post_score（新）= post_score（旧）+ 本轮增量
```

---

## 默认行为与禁止

| 场景 | 行为 |
|:---|:---|
| 文章类型无法确定 | 按「观点评论」(6 分) 处理，标记 `[类型待确认]` |
| 来源无法确定 | 按「原创」(×1.0) 处理，标记 `[来源待确认]` |
| 质量无法判断 | 按「正常」(×1.0) 处理，不做扣分 |
| redis文章被多次提炼 | 只算一次分（首次提炼时计入） |
| 计算结果为小数 | 四舍五入取整 |
| 计算后 post_score < 0 | 保留负数，不强制归零 |

### 禁止行为

- 绝不跳过评分步骤（即便是"无关紧要"的文章也要打分）
- 绝不凭感觉打分（必须有内容类型+来源+质量三者乘积）
- 绝不因为喜欢/不喜欢博主而调高/调低分数
- 绝不叠加扣分系数（取最小值，不连乘）
- 绝不让「偏水」触发负数（×0.5 最低为 0，不倒扣）

## 一、内容类型基础分

```
1. 先看：有没有完整逻辑框架？            → 方法论（10）
2. 再看：围绕单一标的深度展开？          → 案例分析（8）
3. 再看：对某话题有独立判断？            → 观点评论（6）
4. 再看：主体是数据罗列？               → 数据解读（5）
5. 再看：只是描述涨跌？                  → 市场综述（3）
6. 都不沾：                             → 生活随笔（1）
```

| 类型 | 基础分 | 典型特征 | 适用平台 |
|:---|:---:|:---|:---|
| 方法论 / 投资体系 | 10 | 系统性框架输出（仓位规则、选股标准、风控体系） | 长文、帖子 |
| 案例分析 / 个股深度 | 8 | 单一标的深度拆解，含估值/逻辑/风险 | 全平台 |
| 观点评论 | 6 | 对市场/板块/事件有独立判断 | 全平台 |
| 数据解读 | 5 | 以数据表格/图表为核心的分析 | 帖子、长文 |
| 市场综述 / 行情复盘 | 3 | 当日/当周行情描述、事件速评 | 全平台 |
| 生活随笔 / 情绪宣泄 | 1 | 纯个人日常、投资心理吐槽 | 全平台 |

---

## 二、来源权重

| 来源 | 权重 | 判断依据 |
|:---|:---:|:---|
| 原创 | ×1.0 | 博主本人撰写/口述 |
| 深度转述 | ×0.7 | 转述他人但有自己补充分析 |
| 转载 / 简单转述 | ×0.5 | 二次传播无实质原创 |
| 纯引用 | ×0.3 | 仅贴链接/截图/原文，无点评 |

### 平台判定

| 平台 | 原创判定 | 转载判定 |
|:---|:---|:---|
| 雪球帖子 | 非转发=原创 | 转发+无点评=纯引用，转发+点评=深度转述 |
| 抖音/视频 | 博主口述=原创 | 读稿/引述他人=深度转述 |
| 公众号 | 署名作者=原创 | 「转载自」声明=转载 |
| 访谈 | 博主是受访者=原创 | 博主是采访者=深度转述 |

## 三、质量系数（可负数）

质量系数决定本轮增量是加还是扣。按以下顺序扫描，命中即停，取该条系数。

```
扫描顺序：注水严重 → 风格漂移 → 标题党 → 短篇无观点 → 偏水 → 正常
              ↓           ↓          ↓           ↓         ↓      ↓
            ×-1.0      ×-0.8      ×-0.8      ×-0.5     ×0.5   ×1.0
```

| 扫描顺序 | 条件 | 系数 | 标准 |
|:---|:---|:---:|:---|
| 1 | 注水严重 | ×-1.0 | 通篇无独立判断，纯行情数字罗列或情绪宣泄 |
| 2 | 风格漂移 | ×-0.8 | 与博主 `style_keywords`/`markets` 明显背离，非研究性拓展 |
| 3 | 标题党 | ×-0.8 | 标题夸张煽动但正文无实质论证 |
| 4 | 短篇无观点 | ×-0.5 | < 200 字且无明确判断，纯「看好」「牛逼」 |
| 5 | 偏水 | ×0.5 | >50% 篇幅讲日常/情绪/重复，可提炼信息 ≤2 条 |
| — | 正常 | ×1.0 | 以上均不命中 |

### 条件详解

**注水严重**
- 从头到尾「沪指涨 X%」「茅台跌 Y 元」，无一句独立判断
- 或大段情绪宣泄无任何逻辑链条
- 效果：基础分 ×1.0 × -1.0，本轮增量等于负的基础分

**风格漂移**
- 博主长期价值/逆向/消费，突然推短线/技术面/陌生赛道
- 例外：博主明确说「最近在研究 XX 领域」→ 降为偏水（×0.5）
- 判断依据：对比画像 `style_keywords` 和 `markets` 字段

**标题党**
- 标题「暴涨 100%」「99% 的人不知道」「错过后悔一生」
- 正文与标题情绪不匹配或无逻辑论证
- 常见于公众号流量文

**短篇无观点**
- < 200 字（约一条微博），内容「看好」「不看好」无理由
- 纯转发无评论、纯晒持仓无分析
- 注意：精炼短观点（如段永平一句 + 三个理由）不算此列

**偏水**
- 文章大量回忆往事、描述日常、抒发情感
- 投资部分只有「长期看好」「相信价值」类笼统表态
- 效果：基础分 ×1.0 × 0.5，加分减半但不倒扣

## 四、输出格式

每次评分后输出：

```json
{
  "article_title": "文章标题",
  "content_type": "案例分析",
  "base_score": 8,
  "source_type": "原创",
  "source_weight": 1.0,
  "quality_condition": "正常",
  "quality_coefficient": 1.0,
  "round_score": 8,
  "previous_post_score": 16,
  "new_post_score": 24
}
```

> 格式固定、字段固定、类型固定。pipeline 据此更新画像 frontmatter。

## 五、规则来源

| 优先级 | 来源 | 涉及内容 |
|:---|:---|:---|
| 1 | 用户显式约定 | 倒扣机制、偏水不扣负、风格漂移判定 |
| 2 | 工程实践 | 三因子公式（类型×来源×质量）、评分幂等性 |
| 3 | 平台特性 | 雪球转发判定、抖音转录来源、公众号署名 |
| 4 | 投资社区共识 | 「标题党」「生活随笔」等类别定义 |
