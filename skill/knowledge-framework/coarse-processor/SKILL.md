# 粗加工

## 前置

粗加工前先读 **仪表盘/待处理队列.md**，根据粗制品目录下的文件列表确定待处理文件，**不要逐个扫目录**。

## 输入（全部必填）

{source_path, target_dir, type, template_path}

## 流程

1. 读 source_path，校验文件存在
2. 读 {template_path}，按模板补全 frontmatter
3. 原文处理：逐字稿去时间轴格式，整理为连贯段落
4. 保留图片 wikilink 引用
5. 清洗尾部反馈链接
6. 移动文件到 {target_dir}/{type}/
7. 删除源文件

### 原文处理规则

**逐字稿（抖音转录类）**：
- 保留 AI 生成的摘要分段（核心观点、二级市场等），不删减不合并
- 识别「逐字稿」section 下的 `MM:SS` 时间轴行
- 去掉时间标记，将内容整理为连贯段落，**不删减任何原文内容**
- 保持口语化表达，不修正口癖和 Whisper 错误
- 段落间空一行分隔
- 模板：
  ```
  ## {AI摘要分段标题1}
  {原文内容}

  ## {AI摘要分段标题N}
  {原文内容}

  ## 逐字稿
  {去时间轴后的连贯段落·不删减}
  ```

**普通文章**：保持原文不变。

### 清洗规则

- 删除「内容效果不满意？点此反馈」等反馈链接
- 删除末尾「视频时长 X分X秒 · 消耗 X 积分 · 积分余额 X」等统计行
- 删除末尾「阅读原文」「关注公众号」等推广文字段
- 保留作者声明和免责声明

## 自检

- [ ] 目标文件是否存在？
- [ ] frontmatter 所有必填字段非空？
- [ ] 源文件是否已删除？
- [ ] 原文内容与源文件一致？
