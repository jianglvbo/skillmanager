# 帖子集提炼：精华去糟粕判断清单

> 适用对象：xq-post-fetch 产出的 `type: 帖子集` 文件，在「粗制品」阶段直接提炼时。
> 权威规则：`framework-rules.md` #29（帖子集例外流程）。本清单是 #29 的执行版，提炼前必加载、逐条照做。
> 本清单由 xq-post-fetch 采集完成后、交给 investment-refine 执行，采集阶段不分析内容（遵守 SKILL.md 禁止行为）。

## 0. 例外流程（与常规流水线不同）
- 直接从「粗制品」提炼，**不进原始资源**、不置 `status=待提炼`。
- 所有精华落位后，源文件移入 `~/.Trash`（可逆删除，绝不用 `rm`）。
- 框架条目 `source` 写**雪球原文帖子链接**（例：`[标题（博主 日期）](https://xueqiu.com/.../XXXXXX)`，取自本批次该帖的 `[原文]` 链接），**禁止用采集批次文件名**（批次删后不可追溯），避免悬空引用。

## 1. 逐条价值流水线（对每条帖子）
1. **判信息量**：纯情绪 / 调侃 / 段子 / 水帖 → 直接丢（糟粕）。
2. **判具象化**：有信息量且能落成分析框架 / 交易体系 / 投资心得 / 行业等方法论或认知 → **生成框架文件**（精华落地）。
3. **判留存**：不能具象、但观点有留存价值 → 进博主画像「言论追踪」对应子表（具象化 / 观点 / 信号 / 互动）。
4. **判增量**：对已有条目的补充 → 追加进现有文件，不新建重复条目。

## 2. 灰区裁决（拿不准时按此办）
- **有时效但藏框架/理由**（如"今天减仓"）：拆——具体动作/买卖点位/时点删，框架理由留；若框架理由能具象成分析框架文件，判价值，有价值则留。
- **互动/回复类**（博主常回别人）：只取博主**原创观点**，被回复者话当上下文不提炼；能具象成文件的才生成文件，有留存价值的存入言论追踪。
- **调侃/反讽藏观点**（博主常见）：看信息密度——反讽背后观点可提炼则留，纯乐子丢。
- **准确率未验证观点**：不算糟粕，照录进言论追踪并标「未验证」。

## 3. 言论追踪 4 类落位
| 子表 | 进入条件 |
|:---|:---|
| 具象化 | 已生成框架文件，本行仅作指针（`[[wikilink]]` 指向该文件） |
| 观点 | 纯判断/认知，未具象化但值得留 |
| 信号 | 关注/建仓/组合等动作（**强制填「信号」列**：动作/价格/时长） |
| 互动 | 来自回复他人、带上下文（只取博主原创，来源标「雪球回复」） |

> 预测类单列「预测记录」表（带验证状态），不走言论追踪。
>
> 各子表统一列含「原文链接」：填帖子 URL（`[原文](https://xueqiu.com/{xq_id}/{post_id})`，取自本帖 `[原文]` 链接），**禁止留空 `-`**（无来源帖链接则该行不建，见 framework-rules #35）。预测记录 / 个股买卖记录表同样须带原文链接列并填真实 URL。

## 4. 丢弃确认清单（满足任一即丢）
- [ ] 纯情绪/调侃/段子/水帖，零信息量
- [ ] 强时效盘中喊单/具体买卖点，过期即废且无框架残留
- [ ] 模糊个人情绪、无通用迁移价值的碎碎念
- [ ] 与已提炼内容重复、被更高阶条目覆盖的冗余

## 5. 提炼收尾
- [ ] 所有精华已落位（框架文件 / 言论追踪 / 增量补充）
- [ ] 源文件已移 `~/.Trash`
- [ ] 博主画像 `info_cutoff` 已更新（采集第七步已做，此处复核）
- [ ] 新建框架条目 frontmatter 符合 framework-rules 规范（无 `date` 字段、source 描述性）
