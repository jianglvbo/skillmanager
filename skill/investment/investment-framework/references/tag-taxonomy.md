# 标签分类体系

## 全局规则

**层级硬约束**：标签最少二级、最多三级。禁止裸标签（如 `美联储`），必须挂在一级分类前缀下。二级标签本身即完整时可不展开三级（如 `市场/A股`、`宏观/财政政策`）。

**设计原则**：二级回答"是哪类"（少而互斥），三级回答"具体哪种"（按需展开）。二级分类按"区分度最大"的维度划分，重叠的合并，可能属于其他一级的不设。

**归纳性描述**：标签回答"是什么类型"而非"涉及什么细节"。按需选用，不强制填满，宁精勿滥。

**标签与文件夹互补**：文件夹回答"这是什么类型的文件"，标签回答"内容涉及什么维度"。标签的价值在于捕捉文件夹分类无法表达的跨维度信息。判断标准：这个标签描述的是内容的真实特征，还是仅仅复述了文件夹的位置？如果是后者，不加。

**实体描述原则**：标签描述的是它所在实体的性质，不同实体类型用不同标签维度。
- 博主标签 → 描述人的特征（投资哲学、方法论、交易风格、身份）
- 个股标签 → 描述股票的特征（所属行业、所在市场）
- 方法论标签 → 描述方法的特征（分析镜头）
- 心态/心得标签 → 描述知识条目的特征（心理偏误、经验主题）
- 行业/宏观标签 → 描述客观主题（行业分类、宏观事件）
- 博主不应带行业标签——博主关注的行业不等于博主本身的特征

**市场/行业标签使用规则**：`市场/` 和 `行业/` 标签仅在内容确实仅适用于特定市场/行业时添加。通用性的投资心得、心态、框架类内容不强制绑定市场/行业标签。个股文件天然绑定行业和市场，仍需添加。

## 一、分析框架/（5 个二级）

按"分析镜头"划分——每个二级回答一个不同的分析问题。

| 二级 | 回答什么 | 三级示例 |
|:---|:---|:---|
| 分析框架/估值 | 值多少钱 | DCF、均值回归、PE比较、股息折现 |
| 分析框架/基本面 | 财务/经营数据怎么读 | 财报分析、业绩测算、数据跟踪 |
| 分析框架/商业模式 | 为什么能赚钱 | 壁垒分析、平台经济、网络效应 |
| 分析框架/行业分析 | 行业怎么样 | 竞争格局、周期定位、产业链 |
| 分析框架/宏观环境 | 大环境意味什么 | 政策传导、资产配置逻辑、经济指标 |

跨分类引用：可加 `市场/` + `行业/一级/二级`。

---

## 二、交易体系/（3 个二级）

按"投资范式"划分——前两个是靠什么赚钱，第三个是跨范式通用的资金规则。

| 二级 | 是什么 | 三级示例 |
|:---|:---|:---|
| 交易体系/价值投资 | 基于估值/内在价值的规则体系 | 左侧低吸、安全边际、深度价值、均值回归 |
| 交易体系/趋势交易 | 基于动量/趋势的规则体系 | 右侧入场、趋势跟踪、动量止损 |
| 交易体系/仓位管理 | 资金分配规则（跨范式） | 集中持仓、分散配置、再平衡、对冲 |

跨分类引用：可加 `市场/`。

## 三、投资心态/（2 个二级）

按"问题 vs 解法"划分。

### 投资心态/心理偏误/（描述问题）

| 三级 | 含义 |
|:---|:---|
| 损失厌恶 | 对亏损的恐惧超过理性 |
| FOMO | 害怕错过的冲动 |
| 从众心理 | 跟随大众决策 |
| 过度自信 | 高估自己的判断力 |
| 锚定效应 | 被买入价等参考点锚定 |
| 处置效应 | 过早止盈、过晚止损 |
| 确认偏误 | 只关注支持自己观点的信息 |
| 幸存者偏差 | 只看成功案例忽略失败 |
| 叙事谬误 | 被好故事误导判断 |
| 沉没成本 | 因已投入而不愿放弃 |
| 路径依赖 | 被过去经验束缚 |
| 近因偏差 | 过度重视最近发生的事 |
| 心理账户 | 对不同来源的钱区别对待 |
| 后视偏差 | 事后觉得"我早就知道了" |

### 投资心态/心态修炼/（描述解法）

| 三级 | 含义 |
|:---|:---|
| 耐心 | 等待机会的定力 |
| 纪律 | 执行交易系统的自律 |
| 独立思考 | 不随大流的判断力 |
| 逆向思维 | 反共识思考的习惯 |
| 风险意识 | 对风险保持警觉 |
| 情绪管理 | 控制情绪波动 |
| 知行合一 | 认知与行动的一致性 |
| 空仓心态 | 能接受空仓等待 |

跨分类引用：不加市场/行业（心态通用）。

## 四、投资心得/（4 个二级）

心得 = 经验教训。如果内容是"怎么分析"归分析框架；如果是"我悟到什么/踩过什么坑"归心得。

| 二级 | 关于什么 | 三级示例 |
|:---|:---|:---|
| 投资心得/买卖决策 | 买什么、何时买卖的经验 | 选股、择时、止盈止损、估值实操 |
| 投资心得/市场规律 | 市场如何运作 | 周期特征、轮动规律、泡沫识别 |
| 投资心得/投资理念 | 投资应该怎么做 | 价值投资信念、逆向思维、期望值 |
| 投资心得/教训复盘 | 从失败中学到的 | — |

跨分类引用：可引用 `分析框架/` 标签标注方法论维度；仅在内容确实仅限特定市场/行业时加 `市场/` + `行业/`。

## 五、行业/（申万标准）

## 编排规则

编排者根据文件的 category 字段确定默认标签前缀子集，refiner 按内容实际特征从中选用，并允许跨分类引用：

| 文件 category | 默认标签前缀 | 跨分类引用 |
|:---|:---|:---|
| 博主画像/言论 | `bloggers` + `statements` 表 | 不加行业标签 |
| 分析框架 | 分析框架/ | 可加 市场/ + 行业/一级/二级 |
| 交易体系 | 交易体系/ | 可加 市场/ |
| 投资心态 | 投资心态/ | 不加市场/行业（心态通用） |
| 投资心得 | 投资心得/ | 可引用 分析框架/；仅限特定市场/行业时加 |
| 个股 | 行业/一级/二级 + 市场/（必须） | 可标多个行业 |
| 行业 | 行业/一级/二级 | — |
| 宏观 | 宏观/ | 可加 市场/ |

refiner 不自造标签。发现现有标签无法准确描述时标注「新标签建议」。
