# 预测控制台维护

## Default Stance

### 核心原则
- **三文件分工**：个股（具体股票+代码）、行业（申万最下级标签）、市场（A股/港股/美股大盘）
- **去重优先**：录入前必须检查已有记录，重复的不录、只补新内容
- **双向同步**：录入预测控制台的同时，更新对应博主画像的言论追踪
- **倒序排列**：所有表格按预测日期倒序，最新在上

### 禁止行为
- 绝不重复录入已有预测
- 绝不在行业标题写完整路径（只写最下级，如"白酒"非"行业/食品饮料/白酒"）
- 绝不在个股标题省略股票代码
- 绝不用回复日期代替原始判断日期

## Workflow

### 第一步：识别预测内容
从用户输入（截图/链接/文字）提取：预测人、个股/行业/市场、预测内容、目标价、时间框架

### 第二步：判断归属文件
- 有具体股票代码 → **个股预测控制台**
- 行业/板块/商品（白酒、AI、碳酸锂等）→ **行业预测控制台**
- 大盘走势（A股牛熊、港股、美股）→ **市场预测控制台**

### 第三步：检查去重
在目标文件中搜索股票代码或板块名，确认是否已有该预测。已有则跳过，只录入新内容

### 第四步：录入预测记录
按以下字段写入对应表格：

| 字段 | 规则 |
|:---|:---|
| 预测日期 | 原始判断日期（非回复/重申日期） |
| 预测人 | 博主名或"自己" |
| 当前价 | 预测日收盘价（A股÷100，港股÷1000） |
| 预测内容 | 核心判断，保留原文关键表述 |
| 目标价 | 有明确数字则填，否则留空 |
| 目标日期 | 可写区间（如2023~2027+），无明确时间留空 |
| 原文链接 | 雪球URL或"微信截图" |
| 状态 | 待验证/验证中/已验证(正确)/已验证(错误)/已撤销 |

### 第五步：录入言论跟踪（如有）
若同一来源有增强或反驳该预测的新证据，在言论跟踪表追加：

| 字段 | 规则 |
|:---|:---|
| 日期 | 言论日期 |
| 来源 | 博主名或"自己" |
| 观点/事件 | 核心内容 |
| 方向 | 增强/反驳/中性 |
| 原文链接 | URL |

### 第六步：同步博主画像
在对应博主画像的言论追踪「观点」或「信号」子表追加记录，更新updateDate

### 第七步：排序
确保表格按预测日期倒序排列（最新在上）

## Output Format

### 个股标题格式
`## {个股名称}({代码})`
示例：`## 贵州茅台(600519)`、`## 腾讯控股(00700)`

### 行业标题格式
`## {最下级名称}`（按tag-taxonomy申万标准）
示例：`## 白酒`、`## AI与算力`、`## 锂`

### 市场标题格式
`## {市场名称}`
示例：`## A股`、`## 港股`、`## 美股`

### 表格分隔线
`:-----------------`（17个短横线）
