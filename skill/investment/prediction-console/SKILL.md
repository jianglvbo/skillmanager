# 预测控制台维护

## Default Stance

### 核心原则
- **三文件分工**：个股（具体股票+代码）、行业（申万最下级标签）、市场（A股/港股/美股大盘）
- **去重优先**：录入前必须检查已有记录，重复的不录、只补新内容
- **双向同步**：录入预测控制台的同时，更新对应博主画像的言论追踪
- **倒序排列**：所有表格按预测日期倒序，最新在上
- **验证留痕**：状态从待验证/验证中变为已验证(正确)/已验证(错误)/已撤销时，必须同步在「验证记录」表新增一行（验证日期/验证人/验证依据/结果/备注）——状态枚举里禁止夹带证据
- **一段一票**：每只股票独立段落（标题含代码），禁止合并段落（如"神火/云铝"合成一段）；去重一律按代码搜索
- **日期精确到日**：预测日期必须精确到日；月级日期（2026-08）无法排序、拉价、验时，禁止新增，历史遗留行逐步补精确日

### 禁止行为
- 绝不重复录入已有预测
- 绝不在行业标题写完整路径（只写最下级，如"白酒"非"行业/食品饮料/白酒"）
- 绝不在个股标题省略股票代码
- 绝不用回复日期代替原始判断日期
- 绝不在状态枚举内塞证据（如"已验证（实际约-50%）"——证据进验证记录表）
- 绝不为月级日期编造收盘价；拿不到精确日收盘价就留空
- 绝不录入不可证伪/纯叙事言论进预测记录（宏观叙事、情绪判断归言论跟踪表或跳过）

## Workflow

### 第一步：识别预测内容
从用户输入（截图/链接/文字）提取：预测人、个股/行业/市场、预测内容、目标价、时间框架

### 第二步：判断归属文件
- 有具体股票代码 → **个股预测控制台**
- 行业/板块/商品（白酒、AI、碳酸锂等）→ **行业预测控制台**
- 大盘走势（A股牛熊、港股、美股）→ **市场预测控制台**

### 第三步：检查去重
在目标文件中搜索股票代码或板块名，确认是否已有该预测。已有则跳过，只录入新内容

### 第四步：录入预测记录
按以下字段写入对应表格：

| 字段 | 规则 |
|:---|:---|
| 预测日期 | 原始判断日期（非回复/重申日期），必须精确到日 |
| 预测人 | 博主名或"自己" |
| 当前价/参考价 | 个股列名「当前价」=预测日收盘价（不复权，周末/休市取前一交易日）；行业/市场列名「参考价」=商品价格/指数点位，无明确基准留空 |
| 预测内容 | 核心判断，保留原文关键表述 |
| 目标价 | 有明确数字则填，否则留空 |
| 目标日期 | 可写区间（如2023~2027+），无明确时间留空 |
| 原文链接 | 雪球URL或"微信截图" |
| 状态 | 待验证/验证中/已验证(正确)/已验证(错误)/已撤销（严格枚举） |

价格取值（腾讯kline API，不复权）：
`https://web.ifzq.gtimg.cn/appstock/app/kline/kline?param={code},day,{beg},{end},{count}`，收盘价取 day 数组每行第3个字段。
代码前缀：A股 sh/sz + 代码（如 sh600519、sz000933）；港股 hk + 5位代码（hk00700）；美股 us + 代码 + 交易所后缀（纳斯达克 .OQ，纽交所 .N，如 usMU.OQ、usPDD.OQ）；指数：上证 sh000001、沪深300 sh000300、创业板指 sz399006、恒生 hkHSI、标普500 us.INX。

### 第五步：录入验证记录（状态变更时强制）
状态变为已验证(正确)/已验证(错误)/已撤销时，在「验证记录」表新增一行：

| 字段 | 规则 |
|:---|:---|
| 验证日期 | 实际验证日期 |
| 验证人 | 博主名、自己或数据来源 |
| 验证依据 | 可量化的证据（如"实际盈利同比约-50%"、财报数据、价格走势） |
| 结果 | 正确/错误/已撤销 |
| 备注 | 方向与幅度偏差说明等 |

### 第六步：录入言论跟踪（如有）
若同一来源有增强或反驳该预测的新证据，在言论跟踪表追加：

| 字段 | 规则 |
|:---|:---|
| 日期 | 言论日期 |
| 来源 | 博主名或"自己" |
| 观点/事件 | 核心内容 |
| 方向 | 增强/反驳/中性 |
| 原文链接 | URL |

### 第七步：同步博主画像
在对应博主画像的言论追踪「观点」或「信号」子表追加记录，更新updateDate

### 第八步：排序
确保表格按预测日期倒序排列（最新在上）

## Output Format

### 个股标题格式
`## {个股名称}({代码})`
示例：`## 贵州茅台(600519)`、`## 腾讯控股(00700)`

### 行业标题格式
`## {最下级名称}`（按tag-taxonomy申万标准；非申万自定义标签如"AI与算力"允许，但须与全库既有用法一致）
示例：`## 白酒`、`## AI与算力`、`## 锂`

### 市场标题格式
`## {市场名称}`
示例：`## A股`、`## 港股`、`## 美股`

### 段落结构
每段固定三张表：`### 预测记录` → `### 验证记录` → `### 言论跟踪`（顺序固定，验证记录不可省略）

### 表格分隔线
`:-----------------`（17个短横线），段数必须与表头列数一致（预测记录8列、验证记录5列、言论跟踪5列）
