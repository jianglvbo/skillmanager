# 标签分类体系

标签核心原则：**归纳性描述**，回答"是什么类型"而非"涉及什么细节"。按需选用，不强制填满。

---

## 博主画像标签

### 投资哲学（选1-2个核心定位）

| 标签 | 含义 |
|------|------|
| 价值投资者 | 以内在价值为核心决策依据 |
| 成长投资者 | 以业绩增长为核心驱动力 |
| 逆向投资者 | 在市场恐慌时入场，反共识操作 |
| 趋势交易者 | 顺势而为，跟踪趋势做决策 |
| 宏观配置者 | 自上而下，从宏观到资产配置 |
| 指数投资者 | 以指数/ETF为主要投资工具 |
| 事件驱动 | 围绕并购、重组、政策等事件做投资 |
| 套利投资者 | 利用价差、定价错误获取收益 |

> 反例（不应出现）：高股息投资者、现金流投资者、红利低波投资者 —— 粒度太细。

## 投资心态标签

### 心理偏误（描述问题）

| 标签 | 含义 |
|------|------|
| 损失厌恶 | 对亏损的恐惧超过理性 |
| FOMO | 害怕错过的冲动 |
| 从众心理 | 跟随大众决策 |
| 过度自信 | 高估自己的判断力 |
| 锚定效应 | 被买入价等参考点锚定 |
| 处置效应 | 过早止盈、过晚止损 |
| 确认偏误 | 只关注支持自己观点的信息 |
| 幸存者偏差 | 只看成功案例忽略失败 |
| 叙事谬误 | 被好故事误导判断 |
| 沉没成本 | 因已投入而不愿放弃 |
| 路径依赖 | 被过去经验束缚 |
| 近因偏差 | 过度重视最近发生的事 |
| 心理账户 | 对不同来源的钱区别对待 |
| 后视偏差 | 事后觉得"我早就知道了" |

## 编排规则

编排者（本 skill）在提炼预览表中为每行指定分类路径时，同时指定该行应使用的**标签子集**：

| 提炼路径 | 可选标签维度 |
|:---|:---|
| 分析框架 | 框架类型 + 市场 + 行业 |
| 交易体系 | 体系类型 + 市场 |
| 投资心态 | 心理偏误 或 心态修炼 |
| 投资心得 | 心得主题 + 市场 + 行业 |
| 个股 | 行业 + 市场 |
| 行业 | 行业 |
| 博主画像 | 投资哲学 + 方法论 + 市场 + 行业 + 交易风格 + 身份 |

refiner 只从编排者指定的子集中选标签，不自造标签。如果发现现有标签无法准确描述，在输出中标注 `⚠️新标签建议`，编排者收集后统一更新本文件。
