# 脚注分类体系

> 脚注是正文的补充，不是正文的替代品。
> 与 tag-taxonomy.md 同级，是脚注使用的唯一真相源。

## 核心原则

1. **补充而非替代**：脚注提供正文无法容纳的补充信息，不应干扰正文阅读流
2. **有必要才加**：不为加脚注而加，每条脚注都应有明确目的
3. **标签英文命名**：脚注标签用英文关系类型命名，同类递增（`[^type-1]`, `[^type-2]`...）
4. **位置紧贴相关论述**：脚注标记放在正文中相关句子/数据之后，标点之前
5. **定义统一放文末**：所有脚注定义集中在文件末尾的 `## 脚注` section

---

## 脚注分类

| 大类 | 标签 | 用途 | 添加阶段 | 添加位置 |
|:---|:---|:---|:---|:---|
| 关联 | `[^enhance-N]` | 另一条目增强/支持本条论点 | review | 正文相关论述处 |
| 关联 | `[^supplement-N]` | 另一条目补充了本条内容 | review | 正文相关论述处 |
| 关联 | `[^conflict-N]` | 另一条目与本条存在张力/矛盾 | review | 正文相关论述处 |
| 关联 | `[^complement-N]` | 另一条目与本条互补 | review | 正文相关论述处 |
| 数据溯源 | `[^data-N]` | 标注具体数据的来源和截止日期 | 提炼 | 引用具体数据/统计处 |
| 时效标注 | `[^date-N]` | 标注信息的时间适用范围和失效条件 | 提炼 | 时间敏感的判断/结论处 |

---

## 一、关联脚注

### 何时添加
在 **审查（review）阶段** 发现跨条目知识关联时添加。提炼阶段不做关联——避免每次提炼都扫描整个 vault。

### 标签定义

| 标签 | 含义 | 使用场景 |
|:---|:---|:---|
| `[^enhance-N]` | 增强 | 另一条目提供了更多证据或更强论证，支持本条观点 |
| `[^supplement-N]` | 补充 | 另一条目提供了本条未涉及的角度或额外信息 |
| `[^conflict-N]` | 冲突 | 另一条目与本条存在观点张力或矛盾，需要读者注意 |
| `[^complement-N]` | 互补 | 另一条目与本条配合使用更完整，各覆盖不同侧面 |

### 格式规范

正文标记：在相关论述的句子末尾、标点之前插入 `[^type-N]`。

脚注定义（文件末尾 `## 脚注` 下）：

```
[^enhance-1]: [[博主/段永平/投资心得/买股票就是买公司]] — 增强：段永平从企业主角度给出了更强的论证
[^conflict-1]: [[其他/投资心得/错过'时代'是最大的风险]] — 冲突：该文认为应积极追趋势，与本条"不追高"的观点存在张力
```

### 注意事项
- 每条关联脚注必须有 **内容层面的依据**，不可编撰关系
- 同类脚注递增编号：`[^enhance-1]`, `[^enhance-2]`...
- 关联脚注由 review skill 发现并提出，用户确认后才写入

## 二、数据溯源脚注

### 何时添加
在 **提炼阶段**，当正文引用了具体数据、统计数字、财务指标或事实性声明时添加。

### 格式规范

```
[^data-N]: 来源名称 — 数据描述，截至YYYY年M月
```

### 示例

正文：
> 海螺水泥资产负债率仅28.5%[^data-1]，现金流净额连续五年为正。

脚注定义：
```
[^data-1]: 海螺水泥2025年年报 — 资产负债率28.5%，截至2025年12月
```

### 注意事项
- 必须标注数据截止日期，帮助读者判断时效性
- 来源可以是年报、研报、博主原文、官方统计等
- 常识性内容（如"茅台是白酒龙头"）不加数据溯源脚注
- 来源信息应足够具体，读者可据此查证

## 三、时效标注脚注

### 何时添加
在 **提炼阶段**，当正文包含时间敏感的判断或结论时添加。帮助读者快速判断信息是否还"保鲜"。

### 格式规范

```
[^date-N]: 截至YYYY年M月 — 后续需关注{关键变量}是否改变结论
```

### 示例

正文：
> 当前市场几乎没人给这个期权定价[^date-1]。

脚注定义：
```
[^date-1]: 截至2026年7月 — 后续需关注房地产企稳进展和碳中和政策变化，若行业出现结构性衰退则"周期性"判断失效
```

### 适用场景
- 基于当前市场状态的判断（如"当前估值处于历史低位"）
- 依赖特定宏观环境的结论（如"在降息周期中"）
- 涉及具体数值阈值的观点（如"股息率超过4%就有吸引力"）
- 政策相关判断（如"在碳中和限产背景下"）

### 不适用场景
- 纯方法论/框架性内容（如分析方法的步骤说明）
- 定义性内容（如概念解释）
- 长期适用的基本原则

---

## 脚注排列顺序

当同一文件包含多种脚注时，文末 `## 脚注` 下按以下顺序排列：

1. 关联脚注（enhance → supplement → conflict → complement）
2. 数据溯源脚注（data）
3. 时效标注脚注（date）

同类脚注按编号递增排列。

- **模板**：各模板的写作指引中注明了适用脚注类型，详见对应模板文件
- **tag-taxonomy.md**：标签分类体系，与脚注体系互补——标签用于检索分类，脚注用于正文内的精确补充
