# 提炼预览表规则

## 表格格式

```markdown
## 提炼预览

| 分类 | 内容摘要 | 预计归类文件 |
|:---|:---|:---|
| {分类名} | {一句话摘要} | {预计路径} |
```

## 生成规则

1. Agent 读完粗制品内容后，判断帖子中有哪些有价值信息
2. 行按六大分类 + 博主组织：分析框架、交易体系、投资心态、投资心得、个股、行业、博主
3. **只保留有内容的行，没内容的删掉**
4. 博主行只在帖子涉及博主控制台已登记博主时才出现
5. 预计归类文件路径从路径表取值

## 示例

```markdown
## 提炼预览

| 分类 | 内容摘要 | 预计归类文件 |
|:---|:---|:---|
| 投资心态 | 左侧交易要放宽心，看远期 | 博主/段永平/投资心态/左侧交易心态.md |
| 分析框架 | 用PE判断企业价值的方法 | 博主/段永平/分析框架/方法论/PE估值法.md |
| 博主 | 段永平观点更新 | 博主/段永平/段永平.md |
```

## 自检

- 预览表是否覆盖了帖子中所有有价值内容？
- 没内容的行是否已删除？
- 博主行是否仅在涉及已登记博主时出现？
