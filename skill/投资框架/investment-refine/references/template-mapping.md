## 分析框架子分类判断规则（严格执行）

- **方法论**：抽象的分析方法、判断框架、评估模型 → 用 `分析框架-方法论.md` 模板 → 放入 `分析框架/方法论/` 子文件夹
- **分析档案**：用方法论分析具体标的的实例 → 用 `分析框架-分析档案.md` 模板 → 放入 `分析框架/分析档案/` 子文件夹

**判断标准：** 如果内容是"怎么分析"（方法论），放方法论/；如果内容是"对XX公司的分析"（分析档案），放分析档案/。

## 博主层子文件夹规则（严格执行）

- 博主/{博主名}/分析框架/ 下必须有 `方法论/` 和 `分析档案/` 两个子文件夹
- 所有分析框架条目必须放入对应子文件夹，**不允许直接放在分析框架/根目录**
- 我的/ 和 其他/ 下的分析框架不设子文件夹，直接放文件

## 个股子文件夹规则

- 个股按市场分：港股/、A股/、美股/
- 判断市场归属：根据股票代码或公司名称判断

## Tags 规则

### 基本原则
- **精简**：只加对分类检索有帮助的标签，通常 1-3 个
- **分级**：用 "/" 做多级分级，让标签有层次结构
- **有用**：每个标签都应该能帮你找到一类笔记

### 标签层级示例

```
消费/
── 酒业/
│   ├── 白酒
│   ├── 葡萄酒
│   └── 预调酒
├── 农业/
│   └── 养殖
── 零售/

科技/
├── AI/
│   ├── 大模型
│   └── 算力
└── 半导体/

金融/
├── 银行
├── 保险
└── 券商
```

### 各分类 tags 规范

| 分类 | tags 内容 | 示例 |
|:---|:---|:---|
| 个股 | [个股名称, 行业多级标签] | [百润股份, 消费/酒业/预调酒] |
| 行业 | [行业关键词, 行业多级标签] | [猪周期, 消费/农业/养殖] |
| 宏观 | [事件/主题, 政策类型, 日期] | [美联储, 货币政策, 2026-07-03] |
| 分析框架 | [方法论关键词, 适用行业] | [PE估值, 消费/酒业] |
| 交易体系 | [规则关键词, 交易类型] | [仓位管理, 左侧交易] |
| 投资心态 | [心态问题, 场景] | [恐慌卖出, 持仓心态] |
| 投资心得 | [经验关键词, 关联行业] | [周期底部, 消费/农业] |
| 博主 | [平台, 投资风格] | [雪球博主, 价值投资] |

### 禁止的标签
- 产品名/品牌名：#RIO、#威士忌、#茅台
- 过于具体的概念：#ROE<12%、#净现金为负
- 情绪化标签：#太棒了、#踩坑了
