# 投资知识管理 · 全链路总览

本 skill 是整个知识管理系统的**全局地图**，定义数据流、目录约定和 skill 之间的协作关系。本 skill 不包含任何具体操作步骤——这些由各个 skill 各自定义。

---

## 流水线

```
用户粘贴链接
     ↓
待处理链接.md
     ↓
┌─────────────────────────────────────┐
│  link skill：抓取内容 → 粗制品.md   │
│  路由判断 → 写入 _route 等指令字段    │
└─────────────────────────────────────┘
     ↓
粗制品/（按 _route 分流）
     │
     ├─→ _route: 投资知识
     │   ┌───────────────────────────────────────────┐
     │   │  frame skill                               │
     │   │  粗加工 → 原始资源仓库 → 提炼 → 维基仓库   │
     │   └───────────────────────────────────────────┘
     │
     ├─→ _route: 博主分析
     │   ┌───────────────────────────────────────────┐
     │   │  xq-blogger-analysis skill                 │
     │   │  粗制品 → 创建/更新博主画像                │
     │   └───────────────────────────────────────────┘
     │
     └─→ _route: both → 两个框架同时处理
              ↓
         问答看板（提问、审查报告）
              ↓
         回流（迭代更新维基/画像）
```

## Vault 目录约定

```
我的知识库/                           ← vault root
├── 待处理链接.md                    ← 共享入口（link skill）
├── 粗制品/                          ← 共享暂存（link skill 产出）
│   └── 附件/图片/
├── 问答看板/                        ← 共享产出
│   ├── 回流记录.md
│   ├── 审查报告/
│   └── 提问模板/
├── 仪表盘/                          ← vault 根目录仪表盘
│   ├── 维基总览.md
│   ├── 待处理队列.md
│   ├── 博主全景.md
│   └── 变更日志.md
├── 投资分析框架/                    ← frame skill 管辖
│   ├── 原始资源仓库/                ← 提炼素材（帖子/长文/链接/问答）
│   └── 维基仓库/                    ← 知识条目（投资理念/概念/板块/个股/宏观）
└── 博主分析框架/                    ← xq-blogger-analysis skill 管辖
    └── 博主画像/                    ← 每位博主一份 .md
```

**要点**：
- `待处理链接.md`、`粗制品/`、`问答看板/`、`仪表盘/` 位于 vault 根目录，是两个框架共享的资源
- 各子框架内的目录由对应 skill 管辖，其他 skill 不干预

## Skill 角色

| Skill | 角色 | 输入 | 产出 | 管辖目录 |
|-------|------|------|------|----------|
| `link-analysis` | 入口：链接转译 + 路由判断 | URL / 待处理链接.md | 粗制品.md（含 `_` 前缀指令） | 待处理链接.md、粗制品/ |
| `investment-knowledge-framework` | 加工：粗加工 → 提炼 → 问答 → 回流 | 粗制品（`_route: 投资知识`） | 原始资源.md、维基条目.md | 投资分析框架/ |
| `xq-blogger-analysis` | 产出：博主画像创建/更新/查询/联合分析 | 粗制品（`_route: 博主分析`）、雪球帖子 | 博主画像.md | 博主分析框架/博主画像/ |

**解耦原则**：三个 skill 各自只描述自身领域的操作手册，不引用其他 skill 名字。AI 根据任务性质自然选择对应 skill。

## Frontmatter 通信协议

`_` 前缀字段是流水线各环节之间的内部通信机制，在粗制品创建时写入，沿流水线传播，提炼完成后清除：

| 字段 | 类型 | 写入方 | 用途 |
|------|------|--------|------|
| `_route` | string | link skill | 路由方向：`投资知识` / `博主分析` / `both` |
| `_profile` | boolean | link skill | 是否需要创建/更新博主画像 |
| `_alias` | string | link skill | 博主别名（用于文件命名） |
| `_xueqiu` | boolean | link skill | 是否雪球来源 |

**生命周期**：
1. **粗制品**：link skill 写入 `_` 前缀字段
2. **粗加工**：原样复制到原始资源 frontmatter
3. **提炼**：读取辅助判断来源和关联，完成后从原始资源中**删除**
4. **维基/画像**：不保留 `_` 前缀字段——相关信息已融入 `sources`、`tags` 等正式字段

## 数据归属原则

- **Vault 只存人类阅读的知识产物**：原始资源、维基条目、博主画像、问答产出、仪表盘
- **Skill 目录存机器数据**：`registry.json`（博主索引）等 AI 使用的数据索引只存在 skill 目录，不进 vault
- **Skill 是操作手册**：流程规则、模板、标签、审查规则等 AI 操作指南全部封装为 skill，vault 内不放框架配置文件
