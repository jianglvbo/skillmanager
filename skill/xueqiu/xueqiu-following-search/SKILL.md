# 雪球关注用户帖子搜索

在雪球(xueqiu.com)上搜索用户关注的人中匹配关键词的帖子，并整理为熊掌记笔记。

## 前置条件

- 用户已在浏览器中登录雪球账号
- 需要浏览器自动化工具 (agent-browser skill)
- 输出到熊掌记时需要 Bear MCP Server（需 Agent 已连接 Bear MCP）

## 核心工作流

### 第1步：获取关注列表

1. 导航到关注列表页面：`https://xueqiu.com/center/#/friends`
2. 这是一个 SPA 页面（hash 路由），每页显示 20 个用户
3. 翻页方法：通过 JavaScript 点击分页链接

```javascript
// 点击第 N 页
Array.from(document.querySelectorAll('a')).find(a => a.innerText === 'N').click();
```

4. 对每一页，用 `get_page_text` 或 JavaScript 提取用户名：

```javascript
// 提取当前页所有用户名
document.body.innerText
```

5. 汇总所有用户名到一个数组，记录总数。

**注意**：翻页后需等待 2 秒让 SPA 渲染完成再提取内容。

### 第2步：关键词搜索

对每个关键词，使用雪球搜索 API：

```
https://xueqiu.com/k?q={关键词}&type=11
```

- `type=11`：综合搜索（推荐，结果最全）
- `type=post`：仅讨论帖
- `type=user`：仅用户

**搜索策略**：
- 单关键词搜索效果最好（如 "书"、"港股"、"白酒"）
- 组合搜索用空格分隔（如 "管我财 书"），搜索特定用户的相关帖子
- 雪球搜索不支持 OR 语法

**关键词组合建议**（按场景）：

| 场景 | 推荐关键词 |
|------|-----------|
| 书籍推荐 | 推荐书、好书、读书、书单、投资书 |
| 个股分析 | 股票名/代码 |
| 投资策略 | 策略、仓位、持仓 |
| 行业分析 | 行业名（白酒、医药、新能源等） |

### 第3步：匹配关注用户

获取搜索结果后，检查每条帖子的作者是否在关注列表中：

1. 搜索结果页面中，每条帖子开头有 `用户名 + 时间` 格式
2. 用 `get_page_text` 获取结果全文
3. 将帖子作者与关注列表比对

**高效搜索法**：对高产用户（帖子数 > 5000），直接用 `用户名 关键词` 组合搜索，可精确定位该用户的相关帖子。

### 第4步：提取与整理

对每条匹配结果，提取：
- 帖子作者（关注用户名）
- 帖子核心内容（摘要，不超过 200 字）
- 帖子 URL（如能从搜索结果中获取）
- 相关关键词匹配上下文

### 第5步：写入熊掌记

使用 Bear MCP Server 创建笔记：

```
工具: mcp__bear__create_note
参数:
  title: "{主题}搜索结果"
  content: |
    # {主题}搜索结果

    > 搜索关键词：{关键词}
    > 搜索范围：雪球关注用户（{N}人）
    > 整理时间：{日期}

    ## 搜索结果

    ### 1. {用户名}
    {帖子内容摘要}

    ---

    ### 2. {用户名}
    {帖子内容摘要}
    ...（完整 Markdown 内容）
  tags: ["雪球", "关注", "{关键词}"]
```

如需在创建后打开笔记：
```
工具: mcp__bear__open_note
参数:
  id: "返回的笔记ID"
```

## 笔记格式模板

```markdown
# {主题}搜索结果

> 搜索关键词：{关键词}
> 搜索范围：雪球关注用户（{N}人）
> 整理时间：{日期}

## 搜索结果

### 1. {用户名}
{帖子内容摘要}

### 2. {用户名}
{帖子内容摘要}

---

## 脚注

[^1]: {补充说明}
[^2]: {补充说明}
```

## 注意事项

- 雪球搜索结果为综合排序，非严格按时间排列
- 关注列表翻页是 SPA 内操作，URL 不变，需等 JS 渲染
- `get_page_text` 返回的是 article 标签内的内容，可能不完整；用 `javascript_tool` + `document.body.innerText` 获取完整内容
- JavaScript 变量声明（`var`/`let`/`const`）返回 undefined，需用表达式形式获取返回值
- 搜索无结果时不要跳过，可能是关键词问题，换个同义词重试
- 高产用户（帖子 > 10000）搜索结果最多，优先搜索
- 熊掌记 URL scheme 对长文本有长度限制，超过时改用 sqlite3 写入
