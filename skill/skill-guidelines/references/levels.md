# Skill 级别分类

| 级别 | 判断条件 | 最少结构 |
|:---|:---|:---|
| 🟢 轻量 | 单一操作、无分支决策、规则 ≤ 5 条 | `SKILL.md`（YAML + Default stance + Workflow + 自检） |
| 🟡 标准 | 3-7 步流程、规则 > 5 条 | + `references/` 子文件 |
| 🔴 重量 | 多模式路由、方法论驱动、多 Skill 组合 | + `assets/` 模板 + `scripts/` 脚本 |

## 判级方法

1. 看 Workflow 步数：≤3 步 → 轻量，4-7 步 → 标准，>7 步 → 考虑拆分
2. 看分支复杂度：无分支 → 轻量，简单二选一 → 标准，多模式路由 → 重量
3. 看子文件需求：无需 references/ → 轻量，需要 → 标准/重量

## 升级路径

轻量 → 标准：规则增加到 >5 条时
标准 → 重量：需要模板或脚本时
重量 → 多 Skill：单 Skill >300 行时拆成 pipeline
