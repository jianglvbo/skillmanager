# 转换规则详解与示例

基于实际案例（全文整理_wb.md → 全文整理_笔记助手.md）提炼的具体规则。

---

## 一、口语填充词清除

| 填充词 | 处理方式 | 示例 |
|:---|:---|:---|
| 呃、呃呃 | 直接删除 | 「呃，首先呢」→「首先」 |
| 啊（语气词） | 直接删除 | 「一四年的时候啊」→「2014 年」 |
| 呢（句末语气） | 删除或改写 | 「就更不用说了呢」→「就更不用说了」 |
| 这个/那个（指代填充） | 替换为具体名词或删除 | 「这个就也解释了」→「这解释了」 |
| 就是说、换句话说 | 删除 | 保留后文解释内容即可 |
| 对吧、是吧 | 删除 | 书面语不需要反问确认 |
| 嗯 | 直接删除 | — |
| 那（句首连接词堆叠） | 精简 | 「那然后呢」→ 删除 |

---

## 二、口语套话删除

以下套话在口语中起过渡作用，书面语中应整句删除：

- 「废话不多说，直接进干货」
- 「好，我们一起来看……」
- 「好，我们往下来看看」
- 「啊，这个呢就也解释了」
- 「感兴趣的朋友可以自己去看」→ 可简化为「感兴趣的读者可以自行……」
- 「那样子看到这里」
- 「你看……」（引导看图表时）→ 改为直接陈述

## 三、语音识别错误修正

### 3.1 专有名词大小写

| 错误 | 正确 | 说明 |
|:---|:---|:---|
| kevin总 | Kevin 总 | 人名首字母大写 |
| eps / 一ps | EPS | 每股收益 |
| i p o / i p u | IPO | 首次公开募股 |
| q e / qE | QE | 量化宽松 |
| k型经济 | K 型经济 | 经济分化形态 |
| a股 | A 股 | 中国 A 股市场 |

### 3.2 同音/近音错字

| 错误 | 正确 | 上下文线索 |
|:---|:---|:---|
| 正侧底 | 政策底 | 政策+底部，与「情绪底」「市场底」并列 |
| 映映照回 | 映照回 | 重复字，删除多余字 |
| 启发（政策语境） | 齐发 | 「货币地产资本市场政策齐发」= 同时出台 |
| 大面来看 | 大面来看 | 此处正确，意为「从大的方面看」 |

### 3.3 语义断裂修复

语音识别有时会产生语义完全断裂的句子，需要根据上下文重建：

| 错误（语音识别输出） | 修正 | 修复方法 |
|:---|:---|:---|
| 其他表表甚至标包括美股 | 日韩甚至美股 | 根据上下文（前文提到日韩市场）重建 |
| 居民端口走弱 | 居民端走弱 | 「口」为多余字 |
| 二二年的呃上半年的时时候 | 2022 年上半年 | 去重+规范化 |

### 3.4 数字规范化

| 口语形式 | 书面形式 |
|:---|:---|
| 二五年 | 2025 年 |
| 一四年 | 2014 年 |
| 一八年 | 2018 年 |
| 九二四 | 924 |
| 零八年 | 2008 年 |
| 二零二零年 | 2020 年 |
| 二零二六年 | 2026 年 |

规则：年份统一用四位阿拉伯数字 + 「年」。特殊事件代号（如 924 行情）保留数字简写。

## 四、口语→书面语转换对照

| 口语原文 | 书面改写 | 转换要点 |
|:---|:---|:---|
| kevin总还呃呃，吹吹了一下自己 | Kevin 总先写了一句 | 去填充词+口语表达改书面 |
| 人话就是别大仓位干进去 | 说白了就是别大仓位进场 | 「干进去」→「进场」 |
| 你如果只看它这一段的话 | 如果只看这部分描述 | 去掉多余的「你」「它」 |
| 那样子看到这里 | （删除） | 无实质信息的过渡 |
| 太多人坚信港股是跟流动性有很强的这个关系了 | 太多人相信港股与流动性强相关 | 精简+去口语化 |
| 为了呃正确而去写的 | 为了照顾市场预期而写 | 补充语义使表达更准确 |
| 老登 | "老登"（加引号） | 保留原文特色但标注为引用 |
| 无关痛痒的啊，无关痛痒 | 并非重点 | 去重复+书面化 |

## 五、标题切分规则

### 何时切分新章节

1. **话题转换**：从讨论 A 话题转到 B 话题
2. **论证递进**：从「是什么」到「为什么」到「怎么办」
3. **引用切换**：从引用研报内容转到作者个人评论
4. **时间线跳跃**：从现在的分析转到历史复盘

### 标题命名规范

- 名词性短语为主：「弱势的三大根源」「资金面与历史经验」
- 可用冒号分隔层次：「当下的位置：阶段低位，而非历史大底」
- 不用疑问句做标题（除非原文核心问题）
- 同级标题粒度一致

### 实际切分示例

原文（wb 版）连续语流，按话题切分后：

```
### 港股疲软的根源与底部特征     ← 开篇引入 + 研报背景
### 弱势的三大根源               ← 基本面/赛道错配/流动性
### 当下的位置：阶段低位，而非历史大底 ← 估值与风险溢价分析
### 个股与盈利基本面              ← EPS 下调与历史大底对比
### 资金面与历史经验              ← 回购/换手率/政策底
### 后续观察重点                 ← 未来关注方向 + 总结
```

## 六、保留原则

以下内容必须原样保留（仅做语言形式转换）：

1. **作者的判断和观点**：即使与主流不同，也忠实保留
2. **具体数据和引用**：风险溢价数值、年份、指标名称
3. **比喻和生动表达**：「K 型经济」「老登」「语言的艺术」等
4. **推理链条**：从论据到结论的完整推导过程
5. **表格结构**：原文中的表格保留原始格式
6. **情感色彩**：作者的认可、质疑、保留意见等态度
